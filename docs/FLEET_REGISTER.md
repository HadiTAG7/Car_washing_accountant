# الأسطول

الصفحة `https://app.hadialghanim.com/?page=fleet` سجل تشغيلي مستقل.
تسجيل دباب أو تسليم أو صيانة أو حادث أو وثيقة تأمين لا ينشئ أصلًا ثابتًا، ولا مصروفًا، ولا قيدًا أو تسوية.

## البيانات الأولية

بند «الدباب» في التأسيس يسجل 50 وحدة عند مراجعة 27 أكتوبر 2026.
هذا دليل عدد مشتريات، وليس سجل لوحات أو تسليم؛ لا تُنشأ 50 هوية مفترضة منه.

المسار الموصى به: تحميل قالب CSV الفارغ من «تعبئة السجل»، وتعبئته من قائمة اللوحات الفعلية، ثم رفعه ومعاينته.
لا كتابة عند التحميل أو الرفع أو المعاينة. الحفظ يتطلب مراجعة الصفوف وتأكيدًا صريحًا داخل الصفحة.
يمكن الاستكمال بعد توقف الاتصال دون تكرار الدبابات؛ الرقم الداخلي يحدد هوية الإنشاء، وتمنع اللوحة المكررة.
لا يُستخدم استيراد CSV لتعديل سجل موجود أو لتخمين حالة أو تاريخ أو بايكر.

بديل للمصدر: وكيل العمليات يقرأ صفحة Bikes في SSP، من الجلسة المأذونة القائمة، قراءة فقط، ثم يجهز الملف نفسه.
يوثق تاريخ القراءة والتغطية والصفحات الناقصة. لا ينشئ مسار إرسال أو صلاحية أو مفتاحًا جديدًا، ولا يرسل الملف تلقائيًا.
أي خانة لم تثبت من المصدر تبقى فارغة. لا تُحوّل هوية البايكر إلى رقم لوحة أو رقم دباب.

الأعمدة بالترتيب:

| العمود | المعنى |
|---|---|
| internalNumber | الرقم الداخلي الفعلي، مطلوب وثابت بعد الإنشاء |
| plate | اللوحة الفعلية، أو فارغ إن لم تتأكد |
| model | الموديل |
| purchasedOn | تاريخ الشراء YYYY-MM-DD، أو فارغ |
| startupItemId | معرّف بند التأسيس الموجود، أو فارغ |
| status | working أو maintenance أو stopped أو missing؛ اختيار فعلي، بلا افتراضي |
| statusSince | تاريخ الحالة YYYY-MM-DD؛ مطلوب للصيانة |
| policyId | معرّف وثيقة خاصة موجودة، أو فارغ للوثيقة العامة/غير المحددة |

التسليم التاريخي يسجل من تبويب التسليم بتاريخه وبايكره، وليس من CSV.

## الحفظ والحماية

- جداول `fleet_bikes` و`fleet_assignments` و`fleet_maintenance` و`fleet_incidents` و`fleet_policies`.
- قراءة المدير والمحاسب فقط؛ لا قراءة للشريك/المشرف/المشغّل، ولا كتابة مباشرة من المتصفح.
- `fleet_control` داخلي للخادم، لتنظيم معاملات الأسطول وحماية تعارض الأرقام واللوحات وتسليم الدباب/البايكر.
- المسار `fleetSave` يعيد فحص عضوية المدير داخل المعاملة، ويحصر الحقول في بيانات الأسطول.
- السجلات لها نسخة ومعدّل وتوقيت وتاريخ قبل/بعد. لا حذف، ولا ترحيل أو تعديل في حسابات التطبيق.
- لا تسليمين متداخلين لدباب أو بايكر. الإرجاع يغلق سجل التسليم ويتركه محفوظًا.
- الصيانة المفتوحة تستبعد الدباب من المتاح حتى لو كانت حالته المسجلة «شغال».
- تنبيه أكثر من 7 أيام من بداية الصيانة؛ وانتهاء التأمين خلال 30 يومًا، أو المنتهي بالفعل.
- الوثيقة العامة الأحدث ذات البداية المنقضية تغطي العرض العام؛ والوثيقة الخاصة المرتبطة بالدباب مقدمة عليها.
- تنبيه بايكر «بدون دباب» يستخدم قائمة الخاملين نفسها ومسير الشهر؛ تعذر مصدرها يبقى واضحًا.
- رابط المصروف مرجعي على نطاق التطبيق المعتمد؛ التكلفة التشغيلية لا تضاعف أو تعدل مصروف الدفتر.

الترحيل المولد من سجل الجداول يجب تطبيقه قبل دمج الكود. فحص الموقع بعد النشر قراءة فقط؛ لا تعبئة تجريبية للأسطول الحي.
