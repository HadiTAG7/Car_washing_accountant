# رابط المساعد الذكي للشريك — MCP خاص بكل شريك

كل شريك (مستثمر) يحصل على رابط MCP خاص به يلصقه في **Claude** أو **ChatGPT** كموصِّل
مخصّص، فيصير مساعده يقرأ **حصّته وحدها**: نسبته، ورأس ماله، وقائمة دخله، وعدد الغسلات
التي تعادل حصّته.

```
https://<نطاقك>/api/partner-mcp/<الرمز>
```

## ١ — كيف يعمل

| الطبقة | الملف | ما تفعله |
|---|---|---|
| الرمز | `functions/src/partnerMcpKeys.js` | `pmk_` + ٣٢ بايتاً عشوائياً. المخزَّن **بصمته** (SHA-256) لا هو — في `partner_mcp_key_hashes/{hash}` التي لا يقرؤها أي عميل. |
| الإنشاء والإلغاء | `functions/src/handlers.js` → `partnerMcpCreateKey` · `partnerMcpRevokeKey` | من حساب الشريك عبر الباب الموثوق (`api/ledger.js` أو Cloud Functions). الحارس `partnerSelf` يقرّر أيَّ شريك من **الربط** `partners.user_id` لا من الحمولة. الإنشاء تدويرٌ: الفعّال السابق يُلغى في نفس المعاملة. |
| المنفذ | `api/partner-mcp/[secret].js` | Streamable HTTP بلا جلسة. الرمز من المسار → بصمته → المفتاح (فعّال؟) → الشريك (ما زال مربوطاً بنفس الحساب؟) → حدّ معدل ٦٠/دقيقة. أي حلقةٍ تنكسر = **404** واحد. |
| القراءة | `server/partnerMcp/data.js` | Admin SDK ثم **الترشيح بالشريك في الخادم**: سنداته هو وحدها، والغسلات بـ `select` لا يصل منها اسم عامل. |
| القسمة | `server/partnerMcp/scope.js` | `factor = عمالته ÷ مجموع العمالة` — نفس `PartnerViewContext`. و`assertScoped` تمشي على كل ردٍّ وترمي عند أول مفتاحٍ ممنوع. |
| الأدوات | `server/partnerMcp/tools.js` | ست أدوات قراءة، لا كتابة بينها. |

### الأدوات

| الأداة | تجيب |
|---|---|
| `partner_whoami` | من أنا، نسبتي، مجموع العمالة، الأشهر المتاحة |
| `partner_capital` | المطلوب/المسدَّد/المتبقّي، سنداتي، تحصيل ٦ أشهر |
| `partner_income_statement({ month? })` | قائمة دخل الشهر بحصّتي، بتفصيل الحساب |
| `partner_trend({ months? })` | صافي الإيرادات/التكاليف/الربح شهرياً |
| `partner_operations({ month? })` | عدد الغسلات وما يعادل حصّتي («١٠ من أصل ١٠٠ غسلة تعادل حصّتك»)، ومبيعاتها بحصّتي، والمصاريف بالحساب |
| `partner_summary` | كل ما سبق في ردٍّ واحد |

الأرقام تُحسب بدوال التطبيق نفسها (`monthlyStatement`، `operationalWashSales`) ثم تُقسَم مرةً
واحدة، فما يقوله المساعد هو ما تعرضه صفحة الشريك.

## ٢ — ما لا يراه المساعد أبداً

- أسماء العاملين أو رواتبهم أو بياناتهم (لا تُجلب من Firestore أصلاً).
- بيانات أي شريكٍ آخر أو سنداته (الاستعلام مرشَّح بمعرّف الشريك).
- الدفاتر الخام أو أرقام الشركة غير المقسومة (يُرجَع `totalWorkers` وحده).
- أي كتابة — لا أداة كتابةٍ في الملف، ولا متغيّر بيئةٍ يفتحها.

## ٣ — للشريك: كيف تربطه

من التطبيق: **حسابي كشريك ← المساعد الذكي ← إنشاء رابط**. الرابط يُعرض **مرة واحدة**
(مع رمز QR للجوال). إن فقدته: **تبديل الرابط**.

**Claude (claude.ai)** — حسابات Pro/Max: **Customize ← Connectors ← «+» ← Add custom connector**
← الصق الرابط ← (Advanced settings لبيانات OAuth: اختيارية، لا تحتاجها) ← Add. حسابات
Team/Enterprise: يضيفه مالك المنظمة من **Organization settings ← Connectors ← Add ← Custom ← Web**.
ثم فعّل الموصِّل في المحادثة واسأل. (المرجع: مركز مساعدة Claude، محدَّث ٢٠٢٦-٠٨-١١.)

**ChatGPT**: الإعدادات ← **Apps & Connectors** (قد يظهر باسم *Connectors* أو *Plugins* بحسب
إصدار الواجهة) ← Advanced ← فعّل **Developer mode** ← Create ← الاسم ورابط الخادم ← المصادقة:
بلا مصادقة (No authentication) ← احفظ. ثم اختره من «+» في محادثةٍ جديدة. أسماء القوائم في
ChatGPT تتغيّر كثيراً؛ الثابت هو: Developer mode ثم إنشاء موصِّل برابط MCP.

## ٤ — للمدير

في **إدارة الشركاء** عمودٌ «المساعد الذكي»: فعّال منذ متى، وآخر استعمال، وزرّ إيقاف. المدير
لا يرى الرمز — المستند لا يحمله.

## ٥ — ما يحرس الرابط، وما لا يحرسه

- **الشكل يُفحص قبل أي قراءة**: رمزٌ لا يطابق `^pmk_[A-Za-z0-9_-]{43}$` = 404 بلا كلفة.
- **404 لا 403** للمجهول والمُلغى معاً — من يجرّب لا يتعلّم أيَّهما أصاب.
- **إعادة ربط الشريك بحسابٍ آخر** تُميت رابط الحساب القديم فوراً (يُفحص `user_id` في كل طلب).
- **حدّ معدلٍ لكل رمز**: ٦٠ طلباً في الدقيقة، بمعاملةٍ لأن serverless بلا ذاكرة.
- **الرمز يظهر في سجلّات الطلبات** عند المستضيف كأي رابطٍ سرّي (نفس مقايضة `/api/mcp/<secret>`).
  العلاج التبديل من الصفحة، لا الإنكار.

## ٦ — الإعداد على المستضيف

| المتغيّر | لماذا |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | Admin SDK للمنفذ (مطلوبٌ أصلاً لـ `api/ledger.js`). بدونه 503 يسمّيه. |
| `VITE_PARTNER_MCP_BASE_URL` | اختياري — أصلُ الرابط المعروض للشريك حين يكون التطبيق داخل Capacitor (أصله ليس Vercel). |

لا `MCP_SECRET` ولا مفتاح تعمية: الرمز لكل شريك، وبصمته كافية.
