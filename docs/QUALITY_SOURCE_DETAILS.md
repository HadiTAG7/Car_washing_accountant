# مصادر تفاصيل الجودة

صفحة الجودة تجمع قراءات محفوظة مستقلة، ولا تتصل بسويتر مباشرة.

- لقطة المؤشرات: إجمالي كل نوع ووقت قراءته، وصفوفه إن وصلت. يدعم العرض `deductionDetails` القديم أيضًا.
- سجل مراجعة التكتات: قراءة المسار القائم `compensation-review` فقط، دون نسخة أخرى أو تغيير قراراته.
- الحجوزات: شهر الخدمة في `sweater_bookings`، وملاحظات `sweater_raw_payloads` للمعرفات الملغاة المعروفة فقط.

تبقى مبالغ قسم التعويض وكود العميل وخصم الفاتورة والتسوية منفصلة، بوحداتها ومراجعها الأصلية.
لا تجمع التكتات كمبلغ خصم، ولا يحول العرض قبول الاعتراض إلى عكس مالي.
تظهر جميع الاعتراضات المحفوظة للتكت، لا حالة واحدة منتقاة.

## النوع والهوية

الإلغاء الإداري لا يحدد البايكر أو العميل أو الصيانة. التصنيف يتطلب حالة أو سببًا صريحًا.
تظل القراءات المتعارضة أو غير المصنفة ظاهرة، وخارج التصنيفات الثلاثة.
أوقات المصدر في `coverage.extractedAt` لجولات الاستيراد القائمة تحدد ترتيب الملاحظات الخام.
تقارن أيضًا مع `observedAtIso` للسجل وملاحظته الأحدث؛ وقت تعديل قرار المالك لا يجعل الواقعة أَحدث.
عند غياب وقت المصدر يظل الترتيب غير محسوم، ولا يستخدم وقت الحفظ لإثباته.
تعادل الوقت مع اختلاف المبلغ أو دليل الفاتورة يبقي القراءات متعارضة، دون اختيار مبلغ أو هوية.
لا ينقل المحول حالة جديدة مع سبب قديم من السجل المحمي بقرار المالك.

الربط برقم الشركة الخارجي فقط، مع رفض الربط المكرر أو تعارض معرف الموقع المثبت.
اسم الموقع حسب الربط واسم سويتر حقلا عرض مستقلان. غياب اسم المصدر لا يُملأ باسم الموقع.
معرّف البايكر الداخلي في SSP ليس رقم الشركة الخارجي، ولا تستخدم الأسماء للمطابقة التقريبية.

غسلة المحفظة أو Promocode أو مبلغ 20 ريالًا ليست وحدها دليل غسلة مجانية.
المحول يقبل فقط كمية تعويض صحيحة بوحدة `count`، ومرجعًا يبدأ بنوع المصدر الصريح:
`Compensation type: Free Wash; …` أو `Compensations: Free Wash; …` أو `نوع التعويض: غسلة مجانية؛ …`.
هذا نص دليل ضمن الحقل الحالي `sourceRef`؛ لا حقل أو سياسة أو عقد إرسال جديد.
النص المنفي أو النوع غير المثبت يبقى تكت تعويض، ولا يدخل تفاصيل المجانية.

## الفترات والحدود

تكتات الشهر تتبع تاريخ إنشائها المثبت؛ الحجوزات تتبع تاريخ الخدمة.
وقت قراءة المصدر مستقل عن هذين التاريخين وعن وقت لقطة المجاميع.
لا تُعرض صفوف قديمة على أنها تفسير مطابق لرقم أَحدث؛ العدد المصنف وعدد الصفوف والإجمالي مستقلون.
فشل قراءة مصدر لا يحول نتيجته إلى صفر، ولا يحجب المصادر الأخرى المتاحة.
فراغ قائمة الأضرار يوضح نطاق القائمة، ولا ينفي مطالبات في مصادر أخرى.

رابط `compensation_review&ticket=…` يفتح السجل للعرض فقط، دون اختيار نشط أو إعادة فتح الأرشيف.
أزرار متابعة صفوف اللقطة تستخدم مسارها السابق بنسخة البداية؛ تصفح المصادر الأخرى لا يحفظ شيئًا.
لا تغيير في المخطط أو الصلاحيات أو الدفاتر أو المرسل أو الغسلات والعمولات.
