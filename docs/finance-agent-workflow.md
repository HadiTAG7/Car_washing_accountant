# تقارير فريق المالية داخل الموقع

اعتمد هادي مركز المالية وتقارير الأدوار1/2/3. هذا تعديل موضع العمل والأرشيف، وليس تفويضًا جديدًا للمعاملات أو تغييرًا للجداول والنماذج والإفورت وسياسة الإخطار وتسليم المدير وCEO أو حمولة مركز القيادة.

## شرط التفعيل

العمل بهذا المسار يتطلب ظهور `sweater_finance_reports` و`sweater_publish_finance_report` فعليًا في الاتصال المصرح، ونجاح قراءة الأرشيف من خدمته بصلاحية الحساب الحالية. وجود ملف التعليمات أو اسم أداة في نص لا يثبت توفرها أو نشرها. عند عدم توفرها، احفظ تقرير الدور والأدلة المعتادة وسجل تعثر النشر دون توسيع أذونات أو حفظ مباشر في قاعدة البيانات أو إشعار روتيني إضافي لهادي.

## كل جولة قائمة

بعد إنجاز المراجعة المخولة، يبني الدور تقريره الإداري المراجع من أدلته الحالية وينشره تلقائيًا، دون سؤال هادي مجددًا عن نشر التقرير الروتيني. لا يشغّل هذا جولة إضافية أو يوقظ الفريق. يقرأ1 تقارير2/3 المحفوظة ويجمعها دون الكتابة فوق تقاريرهم أو تقرير0.

العقد الفعلي من أداة النشر يحدد الحقول. التقرير يتضمن يوم الرياض، نوع وحدود الفترة، وقت القطع، دور المصدر، عنوانًا وخلاصة، المراجع ووقت المراجعة ومرجع دليلها، مؤشرات بأساسها ووحدتها وحداثتها وتغطيتها، تحذيرات ظاهرة، مصادر وحالات بمعرفاتها ومسؤوليها والخطوة التالية وآخر تحقق، وتفاصيل ثانوية قابلة للفتح. «غير متاح» `null` لا صفر. لا تخلط قيمة الغسلات التشغيلية بالإيراد المرحّل أو التحصيل، ولا تحوّل الحالة القديمة إلى رقم/تحقق حالي.

معرف التقرير ثابت `finance-<dateRiyadh>-<sourceRole>-<period.kind>-<period.from>-<period.to>`. اقرأ المعرف أولًا. إن لم توجد نسخة فاستخدمrevision1 وexpectedRevision0؛ إن سبق حفظ نفس التقرير المتحقق فلا تكرر. التغير الحقيقي بعد تقرير مكتمل ينتجrevision التالية وسبب تصحيح واضح، ولا يعدل النسخة السابقة أو يغير وقت/حقائق الدليل القديم. لا تعرض سرًا أو مرجع قرص محلي للموقع؛ استخدم معرف دليل دائم أو رابط مستند مأذونًا.

بعد النشر تحقق من إعادة قراءة نفس النسخة ومطابقتها؛ سجل المعرف والنسخة والنتيجة في متابعة الدور. لا تصف المهلة أو الاستجابة المجهولة نجاحًا؛ اقرأ الأرشيف/المعرف قبل أي إعادة. فشل النشر لا يضيع الأدلة ولا يعيد معالجة مالية أو يطلق تنبيهًا روتينيًا.

## الحالات التاريخية والحدود

يبدأ الأرشيف من التفعيل. في التقرير الأول انقل الحالات المفتوحة فقط بمعرفاتها الأصلية وآخر تحقق موثق وتغطيتها، مع وصف واضح أنها موروثة لا فحص جديد. لا تستورد تقارير قديمة كأنها صدرت من الموقع وقتها، ولا تحول أرصدة الأمس إلى أرصدة حية. أغلق الحالة فقط بدليل نتيجة؛ تحقق1 الذاتي لا يسمى مستقلًا.

نشر التقرير ليس اعتماد مصروف أو ترحيله أو سدادًا أو إعداد/تقديم إقرار. دور2 يبقى تسجيلًا غير مرحّل، ودور3 مراجعة/مسودة ضريبية والتقديم لهادي، ودور1 مراجعة وتصحيح واعتماد وترحيل محدود وفق مهارته. لا يتغير أي موعد أو مبلغ أو فترة أو صلاحية أو رسالة واتساب أو مسار مركز القيادة بسبب هذا المسار.
